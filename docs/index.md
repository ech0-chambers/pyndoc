# Pyndoc

Embed Python code into Markdown documents to be executed during conversion with Pandoc. Pyndoc includes convenient markup for embedding code, convenient functions for building markup elements, and comprehensive maths typesetting capabilities.

---

## Welcome to the Documentation

Pyndoc is a build-time companion for Pandoc that enables dynamic document generation with Python.

* **[User Guide](user-guide/index.md)**: Guides and examples for Pyndoc markup and code embedding, programmatic markdown construction such as lists and tables, and dynamic mathematics rendering with value substitution and extensive unit handling.
* **[API Reference](api/index.md)**: Detailed reference documentation for all public modules, classes, and functions.
